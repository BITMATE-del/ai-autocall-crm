# K-MARKETS Trading Workspace — UI Preview

국내주식 + CFD 마진거래 통합 웹 트레이딩 인터페이스 시안.

- `npm install && npm run dev`
- 차트: lightweight-charts 기반 생성형 샘플 캔들 및 거래량
- 종목 검색/전환, 현물/CFD 탭, 호가, 주문 입력 등 프론트엔드 인터랙션 데모
- **주의: 시세·차트·호가·자산 값은 샘플. 주문/체결/실거래/가상정산 없음.**
- 실제 거래 지원에는 적법한 증권사 연동, 시세 배포 계약 및 CFD 관련 인허가·위험관리 검토 필요.

이전 CRM 프로젝트는 `backup/ai-autocall-crm-before-trading-demo` 브랜치에 보관되어 있습니다.
